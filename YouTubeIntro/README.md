# Enes Korkmaz YouTube Intro

Bu klasorde YouTube videosu icin 16 saniyelik giris animasyonu bulunur.

## Dosyalar

- `intro.html`: Tarayicida acilan animasyon ve WebM video indirme araci.
- `youtube-kapak.jpeg`: Kanal kapak gorseli.

## Kullanim

1. `intro.html` dosyasini tarayicida ac.
2. Animasyonu kontrol etmek icin `Bastan Oynat` dugmesini kullan.
3. Video dosyasi almak icin `WebM Video Indir` dugmesine bas.
4. YouTube veya video editoru MP4 isterse indirilen `.webm` dosyasini MP4'e donusturebilirsin.
